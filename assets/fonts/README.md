# Website fonts

Presence Web Sans is a Latin/punctuation subset of Adobe’s Source Sans 3, derived from the regular and semibold fonts bundled with the Android app. The outlines are unchanged. The family, full, unique and PostScript names are changed to **Presence Web Sans** to respect the original font’s reserved name, “Source.”
