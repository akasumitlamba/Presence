# Presence 2.1.1

Offline timer reliability, useful Pomodoro controls, and local Wi-Fi sync fixes. Android versionCode: 10.

## Changes

- Added a four-session 25/5 Pomodoro preset, tracking and skip controls, count-up display, and working auto-continue.
- Fixed inflated time from delayed alarms, stopping a waiting plan, project/task continuity, final completion notifications, and stale foreground notifications.
- Preserved project groups across startup; added group selection/creation and task editing/tag assignment.
- Added manual-entry start times and checks against future or overlapping work.
- Improved local sync discovery and retries, simultaneous exchanges, and shared-setting boundaries. Pairing PINs are no longer advertised; outgoing sync sockets use Wi-Fi/Ethernet.
- Disabled Android cloud backup/device transfer. The app remains offline, with no account or cloud service.
- Refined timer progress, phase labels, small-screen duration fields, and pairing input. Fixed ambient sound generation and file-operation errors.

## Installing over 2.1.0

**This release has a different signing certificate from the published 2.1.0 APK. Android will not install it over that APK.** The old signing key was not available locally.

Before uninstalling 2.1.0, use Settings → Save a backup and retain that file outside the app. Separately save any todos and custom alarm audio: the backup does not include those or appearance settings. Then uninstall the old app, install `presence.apk`, and import the backup. Pair devices again if needed. Do not uninstall before saving your data.

38 core tests pass. Release APK build and Android lint pass.
