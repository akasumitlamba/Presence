A few practical things

How do I install it?
  1. Download the APK on your Android device.
  2. Open it. If Android asks, allow installation from the browser or file app you’re using.
  3. Install Presence, open it, and follow the introduction.

For updates, install the new APK over the existing app to keep your data.

On Windows, run the EXE installer. On Debian or Ubuntu, open the DEB with your software installer. On other Linux distributions, install the Flatpak bundle with Flatpak.

Does Wi-Fi sync need the internet?

No. Both devices need the same local network for pairing and sync. The timer, projects, statistics, and todos work offline even when Wi-Fi is off.

Is everything free?

Yes. Every feature is available, including themes, widgets, backups, and local sync. There is no premium tier or account.

Where can I report a problem?

Open an issue on GitHub with your operating system version and what happened.
