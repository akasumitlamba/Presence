Presence

Download Presence

Presence is a focus timer for a phone. The session, the list, and the streak stay on the device.

Install

  1. Allow your browser to download the file.
  2. Allow your phone to install it.
  3. Open Presence.

What it does

Timer
Focus, a short rest, and a long rest. Start or pause a session.
Todos
Add an item, mark it complete, or delete it.
Streak
The days in a row you have logged time.
Widgets
Session, stats, streak, and todos on the home screen. The session widget can start or pause.
Reminders
A daily reminder and a streak reminder, each at a time you set.
On-device
Projects, sessions, and todos stay on the phone.
No account
There is nothing to sign in to.
